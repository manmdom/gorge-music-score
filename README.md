# Gorge Music Score

Royalty-free programmatic background music. `scripts/make_bgm.py` is the lightweight
NumPy bed used in GorgeReels; `references/lemo-pluck.py` is the physically modelled
plucked-string engine from Lemo for richer scenes (needs `numba`).

No copyrighted tracks, no API key. Generated audio is mixed under narration with ducking.
